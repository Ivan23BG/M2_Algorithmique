\begin{definition}
    Un \defemph{problème paramétré} est un langage \(L \subseteq \Sigma \times \bb N\) où \(\Sigma\) est un alphabet fini. 
    Pour une instance \((x, k) \in \Sigma \times \bb N\), \(k\) est le paramètre.
\end{definition}
